It uses `cache_ttl=0`, so it never touches the caching code. I didn't modify or skip it, so you'll need to run it on the VPN to get a fully green run.

- **`weather/cache.py`:**
  - `TTLCache` is built as the docstring describes. Entries expire `ttl` seconds after they were set, and an expired entry is removed when it is looked up.
  - Setting a key again restarts its TTL and moves it to the newest position.
  - When the cache is full, it drops expired entries first, then evicts the entry set longest ago.
- **`weather/client.py`:**
  - `WeatherClient` caches per city, ignoring case, and passes `clock` through to the cache.
  - `cache_ttl=0` turns caching off.
  - It stores and returns copies of the result, so a caller changing the returned dict can't alter the cached one.
