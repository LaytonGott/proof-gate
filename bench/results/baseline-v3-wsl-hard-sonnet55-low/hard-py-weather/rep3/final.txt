- **`weather/cache.py`:** `TTLCache` now stores each entry with an expiry time, and expired entries are removed when they are looked up.
  - Setting a key again restarts its TTL.
  - When the cache is full, it drops expired entries first, then the entry that was set longest ago.
  - `len()` counts only live entries.
- **`weather/client.py`:** `WeatherClient` caches each response under the city name with surrounding whitespace removed and case ignored. It returns copies, so callers can't change what's cached. `cache_ttl=0` turns caching off. If no `clock` is passed, it uses `time.monotonic`.
