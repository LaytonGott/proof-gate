- **`weather/cache.py`**: `TTLCache` is built on an `OrderedDict`. `get` removes an expired entry when you look it up. `set` restarts the TTL. When the cache is full, it first drops expired entries, then evicts the entry that was set longest ago. `len()` counts only live entries.
- **`weather/client.py`**: `WeatherClient` caches results by lowercased city name, so "Paris", "paris" and "PARIS" share one API call. It uses the injected `clock`. `cache_ttl=0` turns caching off. Cached results are copied on the way in and out, so a caller changing a returned dict can't change the cached copy.
